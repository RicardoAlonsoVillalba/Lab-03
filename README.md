# Laboratorio 03: Privacidad, Cumplimiento y Gobierno de los Datos

Este directorio contiene las evidencias, análisis y scripts SQL generados durante la práctica del Laboratorio 03 (Unidad 02).

## Estructura del Proyecto
* `sql/`: Contiene los scripts utilizados para aplicar los principios de minimización, finalidad y control de acceso.
* `evidencias/`: Contiene los archivos Markdown con las respuestas analíticas, matrices de gobierno de datos, mapas de dispersión y reflexión sobre los derechos ARCO y privacidad por diseño.
